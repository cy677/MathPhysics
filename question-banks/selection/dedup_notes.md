# 题目重复与母题家族的复核方法

本模块检查题目是否重复、相近题目是否仍有不同的审题价值，并为代表题抽取和测评分组提供证据。选题结果仍由分类、质检和配额规则共同决定。分组数量和推荐数量以同一源快照重新生成的 [selection_report.json](../curated/selection_report.json) 为准；具体成员见 [duplicate_groups.jsonl](../curated/duplicate_groups.jsonl)。

## 1. 四个概念分别记录

| 概念 | 判定依据 | 用途 | 不应作出的推断 |
| --- | --- | --- | --- |
| 完全重复 | 统一字符、大小写和标点形式后，题文与问题相同，答案一致 | 保留一份，重复记录指向代表题 | 答案冲突时不能直接删除其中一题，应先复核 |
| 数字或姓名变体 | 只替换数量、姓名后，完整题文与所问句的模板相同，数值域与可核查的数量角色相容 | 指导代表题与备用题分配；保留必要的计算难度差异 | 不能因算式都含加法或乘法就认定为重复 |
| 推定故事家族 | 题文相同，或有足够的词序、语境和模板相似证据 | 将同故事的改条件、改所求题组织成对照练习；测评时整族隔离 | 文本相似不等于已经查明原始来源血缘，也不等于所有成员都可互相替代 |
| 教学覆盖分层 | 知识内容、数量关系、所求位置、推理要求和计算难度 | 控制抽题比例，补齐不同关系和难度 | 同一教学类别不是文本重复组；题量增加也不自动意味着知识点增加 |

`duplicate_group` 记录严格模板组；`story_family_id` 和 `assessment_group_id` 记录推定故事家族；`relation_family_id` 由教学分类生成。ASDiv 与 SVAMP 共用基础应用题池的重复组，GSM8K 使用独立的重复组。跨池相似题可以共享测评家族标识，但不会因此合并选题池。

SVAMP 当前源文件没有可逐题核实的 ASDiv 父题编号，因此本模块不补造对应关系。`source_lineage_id` 缺乏确证时保持 `unknown`。跨 ASDiv/SVAMP 的家族关联在报告中明确标为文本推定。

## 2. 文本证据与稳定性

`deduplicate.annotate(records, prefer_key=None)` 返回添加字段后的记录、分组证据和统计，不修改输入记录，也不改变入选决定。记录以 `bank:source_id` 唯一标识。

规范化保留比较方向、时间条件、对象绑定、所问量和数值域。数值允许用阿拉伯数字或常见英文基数词表示；具备大写和句中出现证据的人名可以替换为顺序角色。只有单人物故事统一 `he/she`，多人物故事继续保留这些可能用于判断指代的词。不同物品在全文中的对应关系也保留：只有在完整句式一致、重复计数名词能够一一对应时，才将“球、苹果、李子”等替换识别为同一情境模板。

`semantic_variant_id` 综合所问句、数量的有序角色、数量个数、条件词和数值域生成。计数对象可以抽象为角色，但目标对象之间的对应关系不能交换。分类文案、原库类型名、`subcategory`、质量标签和选题决定均不进入该标识的硬键。

简单算式可以核对操作数在题文中的位置；复杂公式或无法对齐的情况记为 `unknown`，此时依赖完整题面模板提供相似证据，不宣称已经验证了算式等价。

聚类固定按照 ASDiv、SVAMP、GSM8K 的顺序进行，库内按原编号排序，GSM8K 先 `train` 后 `test`。同一完整源快照下，改变输入排列、分类文案或 `prefer_key` 不会改变故事家族及语义变式的标识。`family_anchor` 是建立文本分组的固定锚点；`preferred_family_representative` 是按质检和选题优先级挑选的代表题。后者以及 `duplicate_of` 可以在复核结果变化后调整。

题库升级、增删待审原题或修改规范化规则可能改变分组，因此应同时保存源快照与方法版本。当前方法版本记录在报告的 `deduplication.method_version` 中。

## 3. 模糊检索的边界

检索使用正文内容词的三词片段，每个正文最多使用 10 个较稀有片段，不展开超过 128 条的常见片段倒排表，每个正文最多比较 48 个候选。短题另有计数对象模板的直接索引。内存和候选数量受到限制，不建立全体题目的两两相似度矩阵。

一般词汇匹配同时要求至少 6 个共同内容词、内容词集合相似度不低于 0.62、较短一侧的覆盖率不低于 0.82、正文词序相似度不低于 0.76。完全相同的正文和严格的计数对象模板另行处理。每一成员都与固定家族锚点核对，避免仅通过连续的相似题连接，把不同故事越并越大。

这是一套偏重准确性的保守检索。大幅改写、跨语言翻译、复杂省略、同义替换较多的题目可能漏检。`semantic_variant_id` 也不是完整的语义等价证明：不同问法可能得到不同标识。抽题仍需设置故事家族上限，并用教学关系分层控制比例；不能把未匹配到家族的题目全部视为新增关系。

相似度说明文本匹配程度，不是“题目确属重复”的统计概率。完全同题的答案冲突单独标记，数字或姓名变体只指导推荐与备用分配。上述规则均不代替题意及答案复核。

## 4. 可追溯的例题

| 原题编号 | 复核结果 | 处理依据 |
| --- | --- | --- |
| ASDiv `nluds-0676`、`nluds-0677` | 完全重复 | 都是将同一批铅笔分到教室、余数给图书馆，题文、问题和答案一致 |
| ASDiv `nluds-1235`、`nluds-1540` | 换数值的同模板题 | 都根据每天固定饮水瓶数和已购数量，求最后一天还要补买多少瓶；数值变化可能影响计算难度 |
| GSM8K `train-2484`、`train-6692` | 仅换姓名的同模板题 | 相同礼金、磁带数量与单价、耳机价格，所求都是剩余的钱，适合默认抽取一题 |
| ASDiv `nluds-0002`、`nluds-0005`、`nluds-0006` | 同关系、同所求的物品情境替换 | 均由较小量和“多多少”求较大量，物品名称变化不应增加关系覆盖数 |
| SVAMP `chal-47`、`chal-899`、`chal-179` | 应保留的时段选择变式 | 分别选择不同时间段或全部时段的数量，所需条件不同 |
| SVAMP `chal-6`、`chal-312` | 应区分的所求变化 | 一个问收入与支出的净差，另一个问实际支出，不能当成同一减法练习 |
| SVAMP `chal-109`、`chal-846` | 应区分的比较方向 | 两个人物的比较方向相反，必须保留数量角色的次序 |
| SVAMP `chal-1`、`chal-432` | 应区分的所求变化 | 一个求单包折后价，另一个求折后预算可以买几包 |
| SVAMP `chal-106`、`chal-250`、`chal-530`、`chal-611` | 应保留的对象与范围选择 | 分别围绕红桃、绿桃、每篮全部、所有篮全部选择计算范围 |
| ASDiv `nluds-0664`；GSM8K `train-0021`、`test-0633` | 跨池、跨原始 split 的同故事模板 | 都比较三种邮票的数量后求总数；既应披露跨池相似，也应避免分散到独立测评组 |
| GSM8K `train-3727`、`test-0825` | 原始 train/test 的相似模板 | 都先计算猫粮和狗粮的罐数，再比较两类罐数；容器词和数值变化不能消除测评相似性 |
| GSM8K `train-2601`、`test-0975` | 同故事中的有意义扩展 | 前者求购书还差多少钱，后者增加时薪并求工作时间；可保留教学变式，测评仍按故事家族隔离 |

这些例题用于解释规则，不意味着每题已通过完整质量审核。最终推荐、备用、适配、待审或剔除状态以重建后的逐题台账为准。

## 5. 与现有中文参数化题库的覆盖关系

现有 [catalog.mjs](../../lessons/question-bank/catalog.mjs) 注册了 48 个模板、9 个主题。具体题面由 [generators.mjs](../../lessons/question-bank/generators.mjs) 生成。新增应用题与其主要存在知识和基础关系的重叠；本次没有据此认定中英文题文重复。

| 现有内容 | 已有模板的实际范围 | 应用题补充的重点 |
| --- | --- | --- |
| 整数、分数、小数四则 | 直接计算及若干括号、混合运算 | 从叙述中选择数量与运算，不能将运算符本身重复统计为新增知识点 |
| 购物 | `word.shopping` 求单价乘数量；`word.change` 求付出减花费 | 逆求单价或数量、多项购买、价格比较、所求变化与无关条件筛选 |
| 平均分配 | `word.groups` 已知总数和组数，求每组数量 | 区分求每份多少、可分多少份，以及两者的逆向关系 |
| 行程 | `word.speed` 以已知速度和整小时数求路程 | 逆求速度或时间、多段累计、单位协调；复杂追及、相遇等另作难度筛选 |
| 未知量 | `integer.missing` 为 `□ + 已知加数 = 和` | 在情境中识别初始量、变化量、最终量和比较基准 |
| 余数 | `integer.remainder` 直接求除法余数 | 根据情境选择去尾、进一、求剩余或补足，区分计算结果与问题答案 |
| 分数、百分数 | 已有分数运算、求一个量的几分之几、百分比与折扣 | 分数对应量、基数变化、比例分配和多步部分整体关系 |
| 测量与时间 | 长度、质量、面积单位换算和经过时间 | 在实际叙述中协调单位；英美单位和货币语境需要中文适配 |
| 几何 | 长方形周长、长方形和三角形面积、长方体体积、三角形内角和 | 逆求边长、组合条件与文字建模；已有公式应用不重复计算为新增覆盖 |
| 统计与可能性 | 直接求平均数、极差及简单摸球概率 | 由条件恢复总量或缺失数据、选择正确统计对象，按实际推理要求分级 |
| 公因数与公倍数 | 没有以 GCD/LCM 为独立教学目标的注册模板；约分中的内部计算不等于该类应用题覆盖 | 等长分割、最大分组、周期同步等；需要区分运算练习和情境建模 |
| 重叠集合 | 简单摸球概率没有覆盖两类对象重叠的计数问题 | 交集、并集、重复计数的识别与处理 |

因此，覆盖报告需要同时展示“哪些现有知识得到巩固”和“哪些数量关系、所求位置或条件选择得到补充”。同故事的多个有价值变式可以保留为一组练习，但不应以题目份数代替新增母题或新增关系数。
