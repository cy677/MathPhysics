# 新加坡小学数学：年级目录与数与生活

检索及整理日期：2026-10-01。

“数与生活”把知识介绍、先备知识、生活例子、可调整模型与中文练习连成一个课堂。首页只显示一个入口；旧题库地址和旧活动链接继续进入统一课堂。原48个模型挑战与旧版48种生成题型、练习和作答记录保留。

## 来源与核验范围

主要依据：[2021 Primary Mathematics Syllabus · Updated October 2025](https://www.moe.gov.sg/-/media/files/primary/2021-primary-mathematics-syllabus-p1-to-p6-updated-october-2025.pdf)，以及[新加坡教育部小学课程目录](https://www.moe.gov.sg/primary/curriculum/syllabus)。2021大纲从2026年起适用于P1—P6。

中英文分别检索了“新加坡 小学 数学 教学大纲／课程大纲／基础数学”和“Singapore primary mathematics syllabus P1 P6 / Foundation Mathematics”。中文检索用于定位术语和可比较的课程目录；未找到能逐条核对2025年10月版的官方中文全文。此处中文介绍、例子与学习层次为本项目编写，英文名称用于对照官方主题。1959年的中文《数学课程标准》及把解题策略误列为P6第四内容主线的二级页面未作为年级依据。

官方网站直接正文访问受验证限制，公开PDF下载未获得可用文件；本次读取的是官方文件的搜索索引正文，不能称为逐页视觉审核。已核对2025年10月版印刷页31—36（P1—P3）、39—40（P4几何与统计）、42（P5几何）、43—44（P6）、46—47及50（Foundation相关内容）。P4数与运算、小数及P5数与代数采用[MOE 2024年12月版相应主题](https://www.moe.gov.sg/-/media/files/primary/2021-primary-mathematics-syllabus-p1-to-p6-updated-dec-2024.pdf)补充核对，P5同时与[宏茂桥小学2026年P5数学说明](https://www.angmokiopri.moe.edu.sg/files/3__2026_P5_PTM_Mathematics.pdf)交叉核对；不声称已排除这几页的所有版本细节差异。

新版已核对的分类：P4含展开图与饼图；整数比与初步代数在P6；P5为单位率。速度应用、概率、面积单位换算等原生成题型保留在生活拓展的自由练习中，不列为新版年级目录的必学主题。

## 课程与学习层次

P1—P4为共同课程；P5—P6列出Standard主题，另附Foundation范围。本站“基础”是学习层次，并不等于官方Foundation Mathematics。三条内容主线为数与代数、度量与几何、统计；数学解题贯穿各年级。

| 学习层次 | 组织方式 |
|---|---|
| 基础 | 认识概念，用图和实物完成直接练习。 |
| 巩固 | 联系不同表示，熟练计算和解决生活问题。 |
| 拔高 | 增加逆向思考和条件联系，解释并检验方法。 |

分层练习控制在所选年级和知识点范围内。并非每个题型都用多步计算来增加难度：识别图形等有限题池保留概念练习，通过知识目标引导解释。层次是本站教学组织，不是教育部难度等级，也不对应PSLE成绩档位。

## 按年级分类

### 一年级 · Primary 1

从数小棒、排队和买东西出发，认识100以内的数，把实物、图画和算式联系起来。

先备知识：会配对、分类、数物体，能描述简单规律。

| 分类 | 学习目标 |
|---|---|
| 基础 | 读写和比较100以内的数，理解加减和平均分。 |
| 巩固 | 用位值和数量关系解释计算，读懂长度、时间与图表。 |
| 拔高 | 在本年级范围内倒推未知量，解释规律和选择理由。 |

| 主线 | 中文主题 / English | 年级范围 |
|---|---|
| 数与代数 | 数数与位值 / Numbers up to 100 | 100以内；十位、个位、比较、数列和第1至第10的序数。 |
| 数与代数 | 加减与数量关系 / Addition and Subtraction | 100以内加减；20以内心算；理解加减互逆。 |
| 数与代数 | 相同小组与平均分 / Multiplication and Division | 乘法概念，积在40以内；平均分，被除数在20以内。 |
| 数与代数 | 认识钱币 / Money | 以分计数到1新元；以新元计数到100新元。 |
| 度量与几何 | 用厘米量长度 / Length in centimetres | 厘米cm；读尺、比较、画整厘米线段。 |
| 度量与几何 | 认识钟面 / Time to 5 minutes | 读时刻到5分钟；上午下午；1小时与半小时。 |
| 度量与几何 | 认识与拼合平面图形 / 2D Shapes | 长方形、正方形、三角形、圆、半圆、四分之一圆；网格临摹。 |
| 统计 | 读懂象形统计图 / Picture Graphs | 一幅图代表一个对象的象形图。 |

### 二年级 · Primary 2

把数的范围扩大到1000，建立乘除关系，开始用分数表示整体的一部分。

先备知识：100以内加减，十位与个位，基本图形和5分钟刻度。

| 分类 | 学习目标 |
|---|---|
| 基础 | 掌握三位数与2、3、4、5、10乘法表，认识简单分数。 |
| 巩固 | 联系乘除、时分、钱币和有刻度图表，解决直接应用。 |
| 拔高 | 通过未知量、图表反推和多种表示说明关系。 |

| 主线 | 中文主题 / English | 年级范围 |
|---|---|
| 数与代数 | 三位数与奇偶 / Numbers up to 1000 | 1000以内；百十个位、比较、数列、奇数和偶数。 |
| 数与代数 | 三位数加减 / Addition and Subtraction | 最多三位数的加减算法及加减一、十、百的心算。 |
| 数与代数 | 乘法表与除法 / Tables of 2, 3, 4, 5 and 10 | 2、3、4、5、10乘法表及相应除法。 |
| 数与代数 | 整体的一部分 / Fractions of a Whole | 分母不超过12；单位分数、同分母比较与一个整体内的同分母加减。 |
| 数与代数 | 新元与分的表示 / Dollars and Cents | 钱币小数表示、比较、转换为分；不提前引入一般小数运算。 |
| 度量与几何 | 米、质量与液体量 / Length, Mass and Liquid Volume | 米m、千克kg、克g、升ℓ；选单位、读测量值和比较。 |
| 度量与几何 | 分钟与经过的时间 / Time in hours and minutes | 时刻精确到分钟；时分长度及双向换算。 |
| 度量与几何 | 图形规律与立体形状 / Shape Patterns and 3D Shapes | 平面图形的大小、方向、颜色规律；立方体、长方体、圆锥、圆柱、球。 |
| 统计 | 带图例的象形图 / Picture Graphs with Scales | 读图例比例并解释象形图。 |

### 三年级 · Primary 3

认识10000以内的数、等值分数和余数，在测量、周长、面积与条形图中使用数学。

先备知识：三位数加减、基础乘法表、同分母分数和时分换算。

| 分类 | 学习目标 |
|---|---|
| 基础 | 完成四位数加减、三位数乘除一位数，认识等值分数。 |
| 巩固 | 用单位、图表与长方形模型连接计算和生活问题。 |
| 拔高 | 逆向寻找条件，说明分数、单位与余数的合理性。 |

| 主线 | 中文主题 / English | 年级范围 |
|---|---|
| 数与代数 | 四位数与乘除 / Numbers up to 10000 and Operations | 四位数加减；6—9乘法表；三位数乘除一位数和余数。 |
| 数与代数 | 等值、约分与相关分母 / Equivalent and Related Fractions | 等值与最简分数；分母≤12；比较；一个整体内相关分母的加减。 |
| 数与代数 | 购物与找零 / Money in Decimal Notation | 以钱币小数表示进行加减。 |
| 度量与几何 | 复合单位与换算 / Compound Units | km/m、m/cm、kg/g、ℓ/ml；复合单位与较小单位互换。 |
| 度量与几何 | 时间线与24小时制 / Time and the 24-hour Clock | 秒；由起点、终点、时长中的两个求第三个；24小时制。 |
| 度量与几何 | 周长与面积 / Area and Perimeter | 直线边图形周长；长方形、正方形面积；cm²与m²，不做二者换算。 |
| 度量与几何 | 直角、垂直与平行 / Angles, Perpendicular and Parallel Lines | 辨认直角及较大、较小角；垂直与平行；画对应线。 |
| 统计 | 条形图与刻度 / Bar Graphs | 读取条形图，使用不同纵轴刻度。 |

### 四年级 · Primary 4

把整数、分数和小数联系起来，用测角、对称、展开图和统计图解决更丰富的问题。

先备知识：等值分数、长方形面积与周长、单位换算和条形图。

| 分类 | 学习目标 |
|---|---|
| 基础 | 认识100000以内的数、因数倍数、带分数和三位小数。 |
| 巩固 | 熟练分数加减、小数运算，读取折线图与饼图。 |
| 拔高 | 利用逆向关系、组合图形和空间推理解释结论。 |

| 主线 | 中文主题 / English | 年级范围 |
|---|---|
| 数与代数 | 大数、因数与运算 / Whole Numbers and Factors | 100000以内；取近似值；因数倍数；四位×一位、三位×两位、四位÷一位。 |
| 数与代数 | 带分数与分数加减 / Mixed Numbers and Fraction Operations | 带分数与假分数；一组物品的分数；分母≤12、最多两种分母的加减。 |
| 数与代数 | 小数位值与运算 / Decimals up to 3 Decimal Places | 认识三位小数；加减和乘除一位整数使用最多两位小数；指定精度。 |
| 度量与几何 | 组合面积与未知边 / Composite Rectangles and Squares | 由面积、周长倒推边长；组合长方形和正方形的面积与周长。 |
| 度量与几何 | 量角与图形性质 / Measuring Angles, Rectangles and Squares | 角的命名、测量和作图；长方形与正方形性质，不含对角线性质。 |
| 度量与几何 | 轴对称 / Line Symmetry | 辨认对称图形与对称轴，在方格纸上补全图形。 |
| 度量与几何 | 立体表示与展开图 / Nets and 2D Representations | 立方体、长方体、圆锥、圆柱、棱柱、棱锥的二维表示；立方体、长方体、棱柱、棱锥的展开图。 |
| 统计 | 表格、折线图与饼图 / Tables, Line Graphs and Pie Charts | 补全表格，读取折线图和饼图；不提前要求用扇形角计算百分比。 |

## 页面与练习覆盖

学习顺序为“认识知识 → 动手理解 → 分层练习”。共49个主题组，每组有中英文名称、知识范围、先备知识、概念要点和生活例子；各年级有基础、巩固、拔高目标。原模型按可对应的主题连接，所有48个挑战也可以通过“生活拓展（原有挑战）”访问。没有对应旧模型的主题使用知识例子和生成题，不虚称拥有可拖动模型。

每个主题组已接入至少一种对应练习。新增29种课程题型，结合原题型在新加坡课程上下文中的参数分支；旧生成器的默认配方和题目不变。知识目录覆盖主题组，不等于所有大纲细项都已有自动练习：作图、实际测量、展开图折叠、复杂组合图形等仍有教学活动层面的覆盖缺口。有限概念题池明确限制题量；未用重复题或别的主题填补题量。

49个知识点的生活例子分别包含题意、3个递进提示、分步过程及常见错误。48个原模型挑战分别增加相同4项题目讲解和“观察什么、怎样操作、为什么这样、生活中怎样用”；每个挑战的操作说明对应它真实的模型。原48种与新增29种合计77种唯一生成模板的教学内容均使用当前题目的参数与数值。知识点的固定例子与当前生成题的讲解分别显示，避免用固定例子代替本题解析。

“基础／巩固／拔高”改变新练习的参数或问法。切换年级和主题只改变新练习设置，上次作答仍保留并显示所属年级与知识点；点击生成后才开始新一轮。旧练习显示“历史自由练习（未按大纲分年级）”，不会伪装为新课程配方。

练习配方包含课程版本、年级、主题、学习层次、数量、题型和名称。导入仅按白名单配方重建题目，不信任文件中的题干、答案或脚本。原存储键继续使用，课堂挑战与练习记录分开保存。
