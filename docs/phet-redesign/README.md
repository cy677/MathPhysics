# PhET 内部 UI 更新与验收

更新日期：2026-09-30。设计方向为“森林运动俱乐部”：奶油白、浅草绿、森林绿和暖黄，人物采用清晰轮廓、友好表情与可辨识的用力姿势。面向小学一年级至六年级，与科学小岛已有页面协调。

运行 `python scripts/serve.py --open`，或双击项目根目录的 `START_WINDOWS.bat`。已提供全部本地运行资源，无需安装前端依赖。停止预览服务可在启动它的终端按 `Ctrl+C`。

## 检查实际实现后所作的改动

上游 PhET 页面包含内嵌的 Scenery 场景图、图片及科学模型，单纯修改宿主 CSS 无法更换内部人物。本次保留 `vendor/phet/` 原始文件，构建四个独立的视觉改编页面至 `src/phet/generated/`，宿主仅对 PhET 切换加载路径。

| 范围 | 实际改动 |
| --- | --- |
| 推箱子、摩擦力、加速度 | 待机、轻推、用力推、跌坐角色；两种施力姿势继续映射原来的31个力度帧索引；左右翻转与运动行为沿用原逻辑。女孩与成人道具的站立、坐姿、举手承重共六个素材同步更新。 |
| 拔河 | 红蓝两队、三种大小、准备和用力姿势；小号伙伴举手够绳，手与绳结、脚与地面校准。保留紫橙队伍配色选择及每位伙伴的原力值。 |
| 滑板 | 默认六位带头盔的人物、左右方向和头像；保留包含义肢的角色表达、质量设置与轨道控制。 |
| 场景与控件 | 森林远景、浅色天空与地面、圆角浅色面板、平面按钮、深绿导航和新版角色缩略图。补齐“秒表”“牛顿”可见标签。 |
| 面积与向量 | 调整内部画布、图形与面板配色、按钮和导航；保留网格、刻度、分量和所有控制。 |
| 学习指引与署名 | 提供可直接照做的中文玩法提示，保留 PhET logo、菜单及版权署名，注明科学小岛视觉改编。儿童界面不显示整合开发说明。 |

人物图集和远景由图像生成工具制作，PNG 裁切、尺寸归一和手部锚点由 `scripts/prepare_phet_assets.mjs` 生成。默认人物已改绘；偏好设置中的地区人物与动物备选图仍保留上游资源。

## 保留边界及验证证据

四个模块共13个实验页面、Area Builder六级挑战和随机题目生成、物理与向量计算均保留。Matter、Tangram、几何证明与航天课堂未改实现；既有开放配置与本地探索记录沿用原机制。

`scripts/build_phet_theme.py` 先核对官方成品的固定 SHA256，再按明确的素材、显示文字、颜色和视图布局条目生成页面。`edit-ledger.json` 记录每一次替换；自动测试逆转全部改动后，必须逐字节还原固定的上游成品。失败时不会把有差异的内容当作原版。

科学计算、题目生成器、评分和状态机没有重写。旧版面积模块在模型构造器中创建显示用的素材桶，该构造器只更换了桶的 `baseColor`；运行函数对比仅规范化这一个明确的颜色替换。

| 检查 | 结果与覆盖 |

浏览器对照可自行复跑：打开 `/tests/phet-runtime.html`，点击“运行检查”。面积旧发行版使用原生 `Math.random`，测试页在测试文档中固定其随机序列，生产页面不改随机生成行为。

视觉验收按用户要求由 Luna / max 独立执行，具体结论见 [视觉验收记录](visual-review.md)。平板通过固定1024×768的实际 iframe 视口检查；不将布局检查描述为实机 iPad 或触屏硬件测试。

## 重建

```text
python scripts/build_phet_theme.py
npm test
python scripts/package.py
```

重新切分插画时才需要 Sharp：执行 `node scripts/prepare_phet_assets.mjs`；可通过 `PHET_SHARP_PATH` 指向已有 Sharp 安装。普通启动、视觉页面重建及离线包使用不需要 Sharp、外部 CDN 或账号。
