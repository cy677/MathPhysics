## 执行顺序与产物

先重建四个离线单文件，再启动带 `/MathPhysics/` 前缀的本地只读静态映射器。浏览器使用独立 context 和外网阻断规则。完成目录及页面族交互后采集截图、尺寸与异常记录；finally 阶段关闭 Chromium 和本地映射器。脚本不得使用现有默认报告/截图路径。

新浏览器日志、JSON 数据和图片放入 `output/playwright/style-unification/<run-id>/`；摘要报告放入 `docs/style-unification/acceptance-report-<run-id>.md`。基线单测日志保存在 `baseline-unit-tests.txt`，不会覆盖项目既有报告。实现变更稳定后才执行完整浏览器矩阵。

本地 Chromium 用 Playwright 1.56.0 和 Chromium Headless Shell 141.0.7390.37。Windows 默认 Playwright 缓存位置当前没有该可执行文件，运行脚本时需要优先使用项目内 `.test-deps/browsers`。本机没有实体 iPad Safari；触屏与 1024×768 均为 Chromium 视口/触控模拟。
