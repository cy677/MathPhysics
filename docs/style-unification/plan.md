## 统一设计规则

### 色彩与字体

创建唯一共享主题文件，例如 src/theme.css。使用有命名空间的 --mp-* 变量，避免覆盖第三方库的内部变量。

| 用途 | 统一值 |
| --- | --- |
| 页面背景 | #f5f3e9 |
| 卡片与表单表面 | #fffef9 |
| 主文字 | #263d33 |
| 次级文字 | #657567（小字也需可读） |
| 主操作、选中 | #315d4b；悬停 #25483b |
| 淡绿辅助面 | #e7eddf |
| 分隔与边框 | #d8ded3 |
| 暖黄强调 | #efc66b；黄色面上用深色文字 |
| 焦点与提醒 | #b87428，轮廓不能只靠颜色变化 |

字体统一采用系统无衬线栈：system-ui、-apple-system、Segoe UI、Microsoft YaHei、sans-serif。不新增联网字体或运行依赖。正文约 15–16px，辅助说明 12–14px，模块标题 24–32px；数学、坐标、读数保留必要的等宽或公式表达。科学图形的功能色可以保留蓝、橙、紫等可区分配色，不能因品牌统一丢失对象身份。

### 控件与布局

- 间距以 4/8px 为基础，常用 8、12、16、24、32px；常规控件圆角 10–12px，卡片 16–20px。浅描边和轻阴影，去掉各模块互不相干的发光或重阴影。
- 主操作森林绿实底，次操作浅色描边，选中态有明确底色及边框/标记；默认、悬停、按下、禁用、键盘焦点都要区分。表单、滑块、复选框、标签页沿用原语义和键盘能力。
- 常用触控按钮至少 44px 高；紧凑目录行在不破坏布局前提下保持可操作。不要全局扩大第三方 canvas 内部控件造成裁切。
- 模块共同呈现“导航与标题 → 操作说明 → 实验和控制 → 解释与反馈”。桌面/平板优先保持实验及主要控制可见；窄屏顺序排布，保证没有横向溢出或不可达操作。
- 公共播放器按实际可用高度分配空间。嵌入模式可紧凑展示子页面页头，独立打开保留完整导航。不要靠固定高度裁掉练习、资料或页面尾部。
- 航天的外壳、导航、面板、按钮统一浅色森林主题；星空 Canvas 保留深色，以维持天体与轨迹对比。Matter 场景改为协调的浅底与清晰实体/约束；不得修改物理量。三维图形的真实边缘不因圆角风格而变形。
- 尊重 prefers-reduced-motion；不得为动画装饰改变物理时钟、几何演示步骤或科学计算。

## 实施路径

1. **共享基础。** 提取主题变量、基础表单/焦点样式与少量真正公用的控件规则；模块仍保留各自布局。不要引入框架、CSS 工具链或大范围组件重写。
2. **宿主及本地课堂。** 首页、工作台、播放器和四个 lessons 引用共享主题；将现有硬编码品牌色、背景与控件映射到主题。检查 SVG 文本/辅助线与新背景对比。用有作用域的规则避免全局 button、nav 影响科学渲染。
3. **第三方运行页面。** Matter 使用 src 展示适配，原示例/引擎不变，动态新增对象也应保持可读；三维 Tangram 通过可追溯的适配入口或可复现派生产物统一实际页面；PhET 沿用当前可逆构建和素材，不直接改 vendor 原文件。入口解析必须保留查询参数、就绪检测、消息来源与单实例销毁行为。
4. **构建同步。** 四个独立文件内联共享主题并保留相对资源/返回行为；若引入派生入口，普通本地启动和现有打包流程都能包含它。必要时更新相应构建脚本和简短维护说明。
5. **检查并修复。** sol 完成语法/构建自检并交接精确修改清单。luna 执行浏览器与现有回归，输出问题；sol 修复；luna 对改动及受影响范围复验。主 Agent 抽查截图和差异后交付。

## 不可破坏的契约

- 全部活动 ID、推荐列表、年级/主题/搜索语义、本地存储键、配置导入导出格式保持兼容；自定义列表包括全部关闭不能被重置。
- 几何24题、JSXGraph 6实验、七巧板2目标、航天4路线/62节点/8实验/7结构图、Matter48示例、PhET13屏与面积6难度完整保留，以源码与测试最终核对。
- 不修改数学公式、参数范围/步长、容差、评分、随机题目、模型、物理属性、约束和时间线；必要改动仅限显示属性和布局。
- 保留来源、许可证、PhET 标识/菜单、科学前提和可访问性标签。儿童主界面不新增实现说明。
- 不修改固定上游哈希或通过放宽保护测试掩盖变化；vendor 原件保持字节一致。
