## 触屏依据与本项目决策

检索日期：2026-10-02。下面区分标准要求、产品惯例与本项目选择。

| 依据 | 结论 | 本项目应用 |
| --- | --- | --- |
| [W3C WCAG 2.2 目标尺寸最小值](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) | AA 的常规目标至少 24×24 CSS px，另有间距等例外。 | 这是最低边界，不作为主要按钮的设计尺寸。 |
| [W3C 增强目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html) | AAA 建议目标至少 44×44 CSS px，并规定例外。 | 主要按钮 44–48px，优先 48px。手机数独 9 列棋格约 36–40px，优先完整可见且不小于最低目标；不宣称全页达到 AAA。 |
| [W3C 指针取消](https://www.w3.org/WAI/WCAG22/Understanding/pointer-cancellation.html) | 抬起时执行，允许移出取消，较易避免误操作。 | 翻格、填数、模式切换使用抬起或原生 click；扫雷滑动超过 10px、多指或 pointercancel 取消本次点按。10px 是本项目阈值，需触屏测试。 |
| [W3C 拖动替代](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html) | 拖动操作需提供不依赖拖动的单指针替代，适用例外另见原文。 | 图解缩放提供 +/−/重置；高级分析数字和雷数提供按钮。 |
| [MDN touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action) | 浏览器手势与事件取消相互作用；none 会禁用平移缩放。 | 页面保持滚动、双指缩放；不全局设置 none，不用禁止缩放的 viewport。 |
| [Minesweeper.now 官方插旗说明](https://minesweeper.now/faq/how-to-flag-in-minesweeper) | 桌面右键插旗，手机点按翻开、长按插旗；数字周围旗数满足条件时可连开。 | 保留右键；触屏采用更显眼的“翻开／插旗”常驻模式，长按非必需。点已揭数字且旗数匹配时连开，并说明错误旗帜也可能导致失败。 |
| [Sudoku.com 官方笔记说明](https://sudoku.com/sudoku-rules/notes-in-sudoku/) | 候选笔记用于记录空格中可能的数字并支持推理。 | 先选格再点 1–9 数字盘，“填写／笔记”显式切换，笔记与正式数字大小明显不同。 |

键盘功能与鼠标操作保留。触屏不要求双击、鼠标滚轮、双键同时按或悬停才可完成核心功能。所有页面可纵向滚动；宽扫雷棋盘只在自己的容器滚动，配提示与格子大小选项；拖动查看棋盘不翻格、不插旗，同一触摸不能再触发合成鼠标事件导致双操作。

## 扫雷功能与操作合同

默认新手 9×9、10 雷，保留三档标准难度与自定义、首步安全、No Guess、种子与同盘重玩、提示/概率/自动求解、求解风格、分析编辑、MBF/ABF/.mine/复盘文件导入导出。高级功能折叠可达，不删减成示范游戏。No Guess 遵循上游生成能力，不把耗时生成描述成即时保证。

棋盘上方常驻“翻开／插旗”按钮及当前操作说明。点击已插旗格在翻开模式不揭示；插旗模式再次点该格取消旗帜。连开仅在周围旗数与数字相同时执行。大棋盘保持可点的格子（至少约 28–32px），默认格子适配 9 列；不能为了装下 30 列而缩成难以点选的小格。分析编辑提供 0–8 数字盘、雷数增减和可见文件选择入口，不依赖滚轮或拖放文件。

独立 `mathphysics.minesweeper.*` 存储完整局面、模式及必要设置，刷新与退出再进可恢复；存储失败显示清楚状态。胜负、恢复和新局状态不得混淆。上游原始脚本、许可证和所有高级能力保留。

## 数独功能与操作合同

保留实际 3014 道题、五档难度、候选笔记与自动候选、冲突/错误显示、撤销/重做、便笺复制粘贴、暂停/计时/自动存档、题集、自建题与唯一解检查、多语言、桌面键盘及深色主题。

先选棋格再点屏幕上的 1–9；“填写／笔记”模式可见且可直接切换。擦除、撤销、重做、提示均有可点按钮。原题数字锁定；选中格、同行列宫、相同数字与冲突有清晰层级。手机不唤起系统软键盘遮挡棋盘。数字盘主要目标 44–48px，宽度不足时合理分行；棋盘完整显示，不让整页横向溢出。

独立 `mathphysics.sudoku.*` 存储，保留原存档能力但避免原项目通用 key 与其他模块冲突。Vite 资源基址为相对路径；原 Hash Router 保留；PWA 的 scope 和 start_url 只覆盖数独目录，不能控制本站其他模块。字体、题库、脚本和图像均使用本地文件。

新游戏成品预先构建并保存，普通启动/服务器包/离线包无需安装 Node 依赖或访问网络。另提供显式复建命令；普通打包校验成品及源码一致性，发现过期应报错而非暗中联网。打包排除任意层级 `.git`、`node_modules`、临时缓存；保留 MIT 原作者归属。宿主增加分类、活动清单、入口白名单、就绪信号和仅限各自 key 的记录清理。

4. 宿主：两个独立入口、搜索/分类可达、ready 正确、记录隔离、许可说明、构建产物本地完整；范围外模块原有修改不被覆盖。
