共替换 **305 条源图资源**（包括各级 mipmap），新增 **15 张实验菜单图**，并用于底部导航。人物和道具使用内置 `image_gen` 生成，图集与[完整提示词](../../src/phet/assets/expansion/prompts.md)保存在 `src/phet/assets/expansion/`。精确科学图形由 SVG 绘制后生成 PNG，与图集裁切共用 `scripts/prepare_phet_expansion_assets.mjs`。

图片保持原栅格宽高与 mipmap 尺寸。跷跷板 SVG 的小数宽高由 SVG 包装继续保留，避免改变图像质量块的缩放与放置；菜单和导航保留原节点范围、变换与输入监听。物态按压手的方向及指尖位置、电路灯脚分界、探针尖端和电池极性按原图校准。分数切片保留每片 `1/n` 的角度与排列，带分数缩略图明确显示 `1 1/2`。分子图使用实际模拟的元素色：H `#ffffff`、C `#b2b2b2`、O `#ff5500`；浏览器逐像素检查与上游 `Element` 色标一致。

默认人物套装与主实验道具已统一；不同地区的人物偏好选项保留原文化形象。PhET 品牌、署名与许可证保留。

## 重建

正常重建展示页不需要图像生成服务或 Sharp；已准备的生产 PNG 与清单随项目保存：

```text
npm run build:phet
```

只有重新裁图或修改科学矢量图时需要 Sharp。已有依赖环境可通过 `PHET_SHARP_PATH` 指向其模块路径，再执行：

```text
node scripts/prepare_phet_expansion_assets.mjs
npm run build:phet
```

`src/phet/assets/expansion/manifest.json` 固定六个上游文件哈希与每条替换资源。源文件改变、替换表达式不唯一、资源尺寸不匹配时，构建或检查会失败。全部派生修改仍可逐字节逆转到十份原版成品。
