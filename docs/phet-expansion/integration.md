## 风格与入口

首页使用六幅独立SVG图示、儿童中文名称与操作提示，接入主题、年级、搜索筛选。物态与分子归入新增的“微观天地”，首页四个主题在桌面、平板和手机分别排为四列、两列和一列。

内部展示沿用奶油白/浅草绿画布、浅色面板、森林绿导航、暖黄控制与中文字体。分数填色、原子种类、电流方向及其他有科学含义的对象颜色保留。旧版物态和分子模块的菜单构造器及菜单背景常量均改为森林绿。视觉复核发现的可选菜单灰字改为浅草色，旧版导航对森林绿使用深色背景的图标；分数拼拼乐游戏页缺失的简体中文标题补为“选择一个挑战！”。分子目标栏的黑色空槽与官方原版实测一致，保留其原有表现。

原文件位于 `vendor/phet/`，宿主通过 `src/activity-entry.js` 加载 `src/phet/generated/`，保留 `locale=zh_CN&webgl=false&allowLinks=false`。PhET署名、logo与内嵌许可信息继续保留。官方新成品附带的外部Cloudflare统计脚本仅从派生页移除，原文件不改动。

后续图片统一已替换默认人物、主要道具、蛋糕分片、电路实物与冷热图示，并接入15张菜单/导航插画。素材、重建与最新验收见[图片统一说明](image-integration.md)。

## 固定资源与重建

`modules/phet/manifest.json` 管理新增模块的内容、推荐年级和实验页数，`modules/phet/lock.json` 保留分支提供的官方文件大小、URL和SHA-256。`scripts/phet_registry.py` 先校验这六项原文件，将活动和哈希登记到主清单及上游锁文件；已有活动、哈希和仓库快照保留。重复登记不会重复添加活动。

`scripts/build_phet_theme.py` 从固定原文件生成展示页，全部修改按顺序记录在 `src/phet/generated/edit-ledger.json`。逆转记录必须逐字节还原原文件。源文件损坏，或下载器更新后的哈希与主清单原有固定值不一致时，构建停止并要求审查上游版本和显示补丁。

```text
npm start -- --open
npm run build:phet
npm test
npm run test:phet:browser
npm run package
```

正常启动与构建无需再次下载资源。`scripts/sync_phet.py` 用于显式获取官方最新成品，访问 `latest` URL 并更新模块锁文件；更新后的显示补丁仍需审查。离线ZIP与服务器发布包均包含 `modules/`，可在解包后的目录重建全部10项展示页。
