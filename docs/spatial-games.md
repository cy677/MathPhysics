# 空间与逻辑挑战

2026-10-03：将 `本地空间游戏来源集合` 的四项源码迁入项目。桌面原目录及 vendor 原件保留；历史 Tangram/Reflection 记录不作为当前实施要求。

## 入口与完整题库

从首页「逻辑乐园」进入各游戏；也可通过静态服务访问 `lessons/spatial-games/index.html?game=soma`，将 game 换为 rush、merge 或 escape。每个入口只显示当前游戏。选关页列出总数、各层关数和全部关卡，不再仅呈现先前精选的 45 关。

| 游戏 | 基础 / 进阶 / 挑战 | 范围与递进依据 | 积分上限 |
|---|---|---|---:|
| 立体拼块 | 2 / 29 / 21 | 5 个教学子目标、经典立方体、全部 46 个原版题形；原题按轮廓展开程度与遮挡分层 | 12,300 |
| 移车出库 | 3 / 12 / 29 | 3 个教学／衍生盘、全部 40 个固定原盘及网页默认障碍盘；最短解由 2 步递进至 60 步 | 11,400 |
| 2048 合合岛 | 2 / 2 / 2 | 合出 16、32 → 64、128 → 512、2048 | 1,200 |
| 数学飞车 | 8 / 8 / 8 | 八类技能各三层，每局随机生成 8 题；刷新继续本局，重开重新出题 | 4,800 |

共 126 个积分关卡／道路，累计上限 29,700 分。各游戏独立解锁：前面层次总上限的 75% 开启下一层。基础、进阶、挑战单关上限为 100、200、300 分。扩充题库时按旧关卡积分保留已解锁层级，不扣旧分、不授予新增关分；新用户使用完整题库门槛。

拼图与合并达到真实目标获得满分；飞车积分为 `round(层次上限 × 首答正确数 / 8)`。重复挑战只增加 `max(0, 本次分数 − 历史最高分)`。用时、浏览次数、提示次数、道路星星与 2048 局内合并分均不直接累加探索积分。

## 来源核对与实现

`vendor/games/spatial/` 保留 282 个原始源码文件、资源与许可证（排除两个 .DS_Store 开发缓存），SHA-256 见 `import-manifest.json`；官方来源、固定提交与许可证保留于该清单；收集过程的本地路径和历史审计报告仅存私人备份。`scripts/import_spatial_sources.py` 可重现复制并拒绝覆盖内容不同的原件。运行不需要远程题库或额外依赖安装。

- Soma：源码有 46 条附加题形定义，每条均为 27 格，原数字 1—7 严格对应标准七块的正旋转摆法。46 个目标在平移和正旋转去重后仍为 46 个，均不同于经典立方体；经典方块的 240 指不同解法，不是 240 关。正式目录共 52 关，逐题来源行号、稳定 ID、难度依据、见证和去重记录见 `soma-native/puzzle-audit.json` 与 `soma-catalog.generated.js`。保留原 Three.js 场景、旋转球及作品导出；单指拖块／拖空白转视角、双指缩放，触控按钮至少 44px。父层从实际三维姿态重建占格并校验覆盖，菜单自由探索不会误领当前计分关奖励。
- rush：`cmd/forty/main.go` 的全部 40 盘及 `web/app.js` 的独立固定障碍盘均已接入，另保留 3 个教学／衍生盘。旧九关中六个与原题重合的条目沿用旧 ID，不重复增关。全部 44 关有 BFS 最短解见证；斜纹墙体固定不可移动。`generated-rush-data.js` 记录原源文件、行号及解法。拖动一次任意距离算一步，方向按钮一次移动一格。
- 2048：保持单次合并和有效移动后生成一个 2/4 的规则；用方向历史重放存档，不信任存储的胜利标记。
- 数学飞车：复用原八类技能生成器，原系统为各技能七级动态出题，并非固定 24 套题。每个新局使用随机种子，重开获取新种子；存档保存本局种子和回答历史以续玩同一题序。题图使用道路外的紧凑 SVG，40 点按 10×4 排列，答案门及路面无遮挡。自动驾驶、路锥／星星、过门判题、反馈后继续及暂停均保留。旧 v1/v2 存档先继续原固定题序，重开后进入随机模式。

原上游的辅助工具及飞车装扮、每日任务、音频和家长管理界面保留在源码归档中。课堂不请求这些外部运行服务。入口及封面注册位置为 `config/local-activities.json`、`src/assets/spatial/`。

## 保存与宿主接口

记录仍使用 `mathphysics.spatial.v1.*`：`record.<game>.<level>` 为最高分，`session.<game>.<level>` 为局面，`last.<game>` 为续玩位置。`catalog.<game>` 记录题库扩充时保留的解锁层级。原 Soma 六关与 rush 九关 ID、目标／盘面不变。飞车局面内部升级到 v3，不改外部存档键。重开保留最高分；清除工具仍按前缀覆盖这些记录。

存储失败时保留本页最新状态并显示提示，不让磁盘旧副本覆盖内存新状态。积分是当前站点、当前浏览器的本地记录。

入口设置 `window.__mpReady`，提供 `render_game_to_text()`、`advanceTime(ms)`；Soma 异步场景就绪另由 `state.ready` 表示。同源宿主发送 `mp-reset`，返回由宿主处理。四个固定 game 参数仍受入口允许列表约束。

## 构建与验证

`npm run build:spatial` 生成 Soma 适配模块、原题目录与 240 个经典解签名，并生成 rush 完整题库。成品已随项目保留，日常启动无需构建。两个脚本分别支持只读验证：`node scripts/build_spatial_soma.mjs --check`、`node scripts/build_spatial_rush.mjs --check`。

`npm run test:spatial` 校验原始文件、完整目录、逐关见证、积分迁移、随机题序与存档。`npm run test:spatial:browser` 运行综合交互及 Soma 原生专项；`node tests/spatial-games-browser.mjs --skill` 加跑官方游戏客户端。综合检查真实操作全部 rush 关卡、飞车 24 条道路的 192 个自动答案门及 2048 前两关，Soma 专项检查原生操作和正式原题计分。

截图与报告位于 `output/playwright/spatial-games/`、`spatial-soma-native/`、`spatial-rush-full/`、`spatial-escape-random/` 等相应目录。飞车专项验证随机新局、同局刷新、重开及40点完整显示；Soma 真触摸专项验证390与820宽度的单指、双指、取消和大按钮操作。浏览器模拟触摸不等同于真机 Safari 验收。
