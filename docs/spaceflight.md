# 从地球出发 · 太空任务互动课堂 v0.3

事实核对日期：2026-09-28。该模块供小学全年级按教师安排选用，不是要求所有年级掌握全部公式。代码、图形和中文讲解为本项目原创，采用根目录 MIT 许可。

## 内容范围

四条路线完整保留、自由切换。主线共62个流程节点，不是62个不重复知识点。

| 路线 | 节点数 | 内容 |
|---|---:|---|
| 猎鹰9 / 载人龙 / 国际空间站 | 19 | 准备、发射、转弯、气动载荷、分级、上面级推进、船箭分离、飞船启用、交会、接近、对接、驻留、撤离、离轨、尾舱分离、再入、伞降、溅落、回收 |
| 猎鹰9卫星任务 | 10 | 发射、分级、罩分离、部署、在轨测试与服务、寿命结束处置 |
| 长征二号F / 神舟 / 天宫 | 22 | 正常抛塔、四助推器分离、芯级接力、罩分离、船箭分离、交会对接、驻留、撤离、轨道舱分离、制动、推进舱分离、再入、伞降与陆地回收 |
| 长征三号甲卫星任务 | 11 | 三级串联、滑行与再次点火、椭圆转移、部署及后续变轨与工作 |

猎鹰9一级回收是美国两条路线都可访问的并行支线，不塞进飞船返航时间轴。空间站建造的运载关系在结构图解中说明；本版不含逐次历史组装发射、货运补给、出舱活动或异常逃逸的独立任务路线。

“长征甲”暂按长征三号甲解释。神舟使用长征二号F；天和、问天、梦天由长征五号B分别运输。本课使用天宫三舱T字基本构型，不声称包含所有时期的扩展结构。国际空间站是国际合作项目，不是美国独有，也不是由猎鹰9单次发射建成。

## 交互

可播放、暂停、选择节点、拖动阶段进度、切换播放速度。逐阶段播放自动进入下一步，全部节点保持可访问。左侧选中阶段自动滚入目录视野。

原理实验、飞行器图解、探究手册是独立页签。型号图解有可点击的结构卡。知识检查提供答错解释和答对反馈，记录和笔记只写入当前浏览器；存储失败时仍可操作并导出笔记。它们不等于正式成绩、掌握度或工程资格。页面隐藏时暂停动画，宿主退出时移除 iframe。

低年级模式使用较短讲解；中年级补充原因；高年级显示模型公式。所有内容仍可由教师选择，不设置阅读速度或操作速度排行榜。

## 八个原理实验与假设

| 实验 | 可改变内容 | 计算边界 |
|---|---|---|
| 推力 | 推力、质量 | 任意自由飞行小模型，忽略阻力；F/m−g只表示瞬时竖直加速度 |
| 分级 | 空级质量、是否分离 | 真空中固定推力200 N、有效质量100 kg；减重不制造速度跳变 |
| 入轨 | 初始高度、横向速度比例 | 球形地球二体模型，RK4积分一周或至120 km边界；不计算稠密大气 |
| 对接 | 脉冲方向、相对速度、姿态偏差 | 二维短距离相对运动，忽略轨道耦合；显示时间压缩×3，容差仅为教学设定 |
| 太阳翼 | 入射角、阴影 | 正对输出假设100 W，角度从面板法线量起；不是空间站实际功率 |
| 漂浮 | 地面/在轨、人体质量 | 用共同自由落体解释微重力；400 km高度仅用于球形地球估算 |
| 再入能量 | 速度 | 只核算每千克动能，不估计温度、热流、烧蚀厚度或实际安全性 |
| 降落伞 | 面积、空气/真空 | 150 kg模型、恒定密度及阻力系数；不能用于判断真实开伞时机 |

轨道采用 R=6371 km、μ=398600 km³/s²。初始速度为所选高度圆轨道速度的65%—120%；并非所有低于圆轨道速度的情况都会进入大气，要看轨道低点。计算轨迹达到地表上方120 km时停止。“理论最低高度”是无空气数学轨道的参数；负值不表示模型模拟了穿过地球内部的运动。

对接的四方向按钮每次改变一个速度分量0.08 m/s；松开后继续滑行。自动示范通过有界加速度逐步接近，同样检查横向位置、横向速度、闭合速度和姿态，而非直接把图形瞬移到成功状态。成功仅表示此简化模型中的低速捕获，不包含真实锁紧机构及舱门操作。

## 返回流程的版本说明

本版载人龙采用西海岸回收方案：离轨点火后分离尾舱。SpaceX的2024年7月25日更新给出了这一调整；NASA Demo-2历史说明则是先分离尾舱再制动。不能把两套顺序写成一个不分版本的流程。载人龙太阳能电池在尾舱表面，不画成早期货运龙的展开翼；本课不复制NASA资料中的旧着陆地点作为当前任务位置。

神舟采用轨道舱分离、返回制动、推进舱分离、返回舱独立再入的概括顺序。正常任务的抛逃逸塔不是发生紧急逃逸。图形只画简化投影；发动机和助推器的完整数量以文字说明为准。

## 独立版与宿主整合

独立单文件输出为 `dist/MathPhysics-Spaceflight.html`，全部脚本与样式内嵌，无网络运行依赖。用普通桌面浏览器打开；手机和平板的文件预览器可能不执行脚本，应使用浏览器或通过本地静态服务访问。

完整项目中运行：

```bash
python scripts/serve.py --open
```

进入“动力车间”，选择“从地球出发”。原先53个上游活动与24题几何题集未被删除；宿主总计55个活动入口。新安装默认开放5项，旧浏览器设置保留，需要在“老师 / 家长”工作台启用新模块。上游 `config/inventory.json` 未更改；新增内容只在 `config/local-activities.json` 登记。

源码分工：`data.js`保存路线、讲解、实验配置与资料；`math.js`保存数值模型；`draw.js`负责图形；`app.js`管理播放、交互与本地记录；`styles.css`适配布局；`index.html`是宿主模块入口。

```bash
python scripts/build_spaceflight_standalone.py
npm test
# 以下检查需要 Python Playwright 和本机 Chromium，仅是测试依赖，不是运行依赖。
python tests/spaceflight-browser.py
python scripts/package.py
```
