# 几何内容分年级与扩题依据

更新日期：2026-09-30。

## 原则

本次不删除原有面积、体积、对称、旋转、向量、线性变换和七巧板内容，而是增加题目，并把原有互动内容按“推荐首次系统学习年级”重新组织。年级标签用于首页筛选和课堂目录，不表示三套教材完全同序。

中国部分以教育部《义务教育数学课程标准（2022年版）》为上位依据。课标第二学段要求结合实例感受平移、旋转、轴对称；第三学段进一步要求在方格纸上描述和绘制平移、90°旋转、补全轴对称图形，并学习圆、长方体、正方体、圆柱、圆锥的测量与体积等。官方发布入口：
- https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html
- https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582346895190.pdf

教材进度存在差异。例如可读取的苏教版目录显示三年级已有平移、旋转、轴对称的直观内容，四年级进一步安排平移、旋转和轴对称，五年级安排多边形面积，六年级安排长方体/正方体及圆柱/圆锥。新版教材册次仍应以学校实际用书为准。

新加坡部分使用MOE 2021 Primary Mathematics Syllabus P1–P6（Updated Oct 2025）：
- https://www.moe.gov.sg/-/media/files/primary/2021-primary-mathematics-syllabus-p1-to-p6-updated-october-2025.pdf

其中P5明确包括三角形面积、由长方形/正方形/三角形组成的组合图形面积，以及正方体和长方体体积。MathPhysics的“向量相加”和“线性变换网格”不作为小学必修内容宣称，继续保留为六年级拓展。

## 推荐年级

| 年级 | 主要现有内容 | 本次处理 |
|---|---|---|
| 一年级 | 七巧板、图形拼搭 | tangram-flat归一年级；强调拼合、旋转的直观操作，不引入变换术语证明 |
| 二年级 | 轴对称直观 | jsx-mirror归二年级；通过对应点到对称轴等距观察对称 |
| 三年级 | 长方形/正方形面积 | rectangle归三年级；保留单位方格推导，并增加同参数周长问法 |
| 四年级 | 平移、旋转、轴对称进一步学习；运算律的面积模型 | jsx-rotation归四年级；distributive归四年级 |
| 五年级 | 平行四边形、三角形、梯形等面积；长方体/正方体体积与表面积 | parallelogram、triangle、trapezoid、rhombus、cuboid、cuboid-net归五年级；动态三角形实验也归五年级 |
| 六年级 | 圆、圆柱、圆锥、比例缩放；高阶空间推理 | 圆及圆环、圆柱/圆锥、比例与相似归六年级；棱锥、球、勾股、代数恒等式、向量和线性变换明确作为六年级拓展 |

geometry-proofs本身覆盖三至六年级，因此宿主入口保留3—6年级，进入课堂后由题目级年级筛选精确区分。

## 扩题结果

### 看见公式

原有24个主题全部保留。每个主题仍有原来的“直接求目标量”题，同时增加一种不同的第二问法，共 **24个主题、48种问法**。

新增问法不是简单换数字。例如：长方形由求面积扩展到求周长；三角形增加保持面积不变时底与高的反向变化；圆增加周长；圆环增加内半径；长方体在体积与表面积之间切换；圆柱增加高度变化与侧面积；棱锥、圆锥增加同底同高体积比较；球增加半球体积；立体缩放增加面积倍率。参数仍可随机变化，所以“48种问法”指题型，不把随机数值组合重复计数。

### 图形会变魔术

6种JSXGraph模式原来每种2个挑战目标，本次扩展为每种6个，共 **36个挑战目标**：三角形6个目标面积；对称6个镜像点；旋转6个角度；缩放6个面积倍率；向量6个终点；线性变换6组基向量目标。前两个旧目标保持不变，避免破坏已有使用习惯。

## 与原题的关系

本次没有删除或改写原有数学结论。新增第二问法使用同一动态图形，但要求求不同的量或建立不同的关系；JSXGraph新增挑战改变目标条件而不是复制原目标。七巧板保留原方形热身和创意轮廓，没有伪造新的上游拼图资源；每个轮廓增加“可以求助 / 最多求助2块 / 不用自动放置帮助”三档任务，因此形成6张挑战卡。

向量、线性变换、勾股、球体积、棱锥体积和代数恒等式在小学阶段均按“拓展”理解；年级筛选把它们放在六年级只是为了集中管理，不表示中国或新加坡小学课程要求掌握这些内容。
