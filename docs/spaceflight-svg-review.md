# 航天模块 SVG 重绘与长征十号乙回收

核查日期：2026-10-02。源分支 main，基线提交 e5764f08a21a389101bc6a4fdbf2952effa1abfe。
实现分支：feature/spaceflight-svg-cz10b-20261002。不改动 main，不涉及其他活动或持久化数据库。

## 型号核查

原模块将“长征甲”暂定为长征三号甲，包含第三级分离与高轨转移任务。本次依据“乙型号＋一级回收”的要求使用**长征十号乙 CZ-10B**，不是不具备本课回收流程的长征三号乙。原来的三级卫星线改为两级卫星线；神舟仍对应长征二号F，不更换载人发射型号。

国家航天局《我国首次成功实施重复使用运载火箭回收任务》（2026-07-10）公开说明：长十乙两级串联；一级在领航者号船上，通过井字形高强度缓冲拦阻网与箭上挂索机构实现捕获。
https://www.cnsa.gov.cn/n6758823/n6758838/c10761540/content.html

中国航天科技集团《长十乙首飞成功 我国首次实现运载火箭可控回收》（2026-07-10）说明一级采用液氧煤油、二级采用液氧甲烷，一级与二级分离后独立返回并由海上网系捕获。
https://www.spacechina.com/n25/n2014789/n2414549/c4647268/content.html

图中调整姿态、下降、减速、对准等动作是教学拆解，不逐帧复现首飞，不据此宣称实际点火次数、秒表或真实控制律。没有把长十乙画成猎鹰9着陆腿、降落伞或塔架夹持回收。

## 绘图覆盖

原模块没有一批独立照片可逐张替换，全部图像由 Canvas 绘图入口生成。已将完整绘图层改为原生 SVG：任务步骤、火箭/飞船/卫星/空间站结构、地球与轨道、气动与推力箭头、对接、再入、防热、降落伞、海上/陆地返回，以及全部实验图和状态驱动轨迹。

`svg-pen.js` 输出可编辑 path/text/gradient/clipPath，不使用 Canvas、位图底图、image 标签或外部图库。原有计算和控制代码仍独立于绘图层。箭体分段、金属渐变、太阳翼、舱体细节与长十乙回收船/网系均为本项目原创 SVG。

课堂默认打开“步骤图解”，可切换“计算轨迹”。两者明确区分：前者是正常流程示意，后者由教学模型实际状态与成功/失败判据控制。步骤图解的成功画面不会覆盖实验中的失败结果。

回收支线有七个可点选、可播放的图解：分离、调整姿态、下降、点火减速、对准、网系捕获、承托检查。所有回收图保留卫星主线提示。俯视小图解释井字网与挂索机构，侧视图显示一级悬于甲板上方。

共导出 **102 张独立 SVG**：63 个主线步骤、9 张支线图（美国路线各1张、长十乙7张）、21 张结构卡图、9 张实验图。`lessons/spaceflight/assets/manifest.json` 列出文件与 SHA-256；`assets/gallery.html` 可浏览、下载。运行时 SVG 使用同一绘图源，不读取静态快照来伪造动画。页面还有“下载当前 SVG”按钮。

## 教学模型边界

长十乙使用两级模型。一级捕获要求目标误差、速度、姿态、挂索状态和剩余燃料均满足教学条件，不是到达高度就自动成功。捕获平面距基准面20 m是任意教学设置，不代表回收船尺寸、网系真实高度或工程容差。失败和“不回收”不会报告捕获成功。返场RTLS选项不用于长十乙；输入RTLS会明确归一化为海上模式并给出提示。

原有猎鹰9支腿着陆、神舟不回收一级、载人龙返回海面和神舟返回陆地的适用性保留。原有转移轨道知识移为通用拓展，不伪称长十乙首飞执行高轨任务。旧 `system=cz3a` 与中国卫星 `step=third` URL 分别引导到新型号与二级步骤。
