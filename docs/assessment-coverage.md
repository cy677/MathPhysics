# 正式考核覆盖与练习边界

考核目标来自 `server/assessments.mjs`，应用题沿用该目录的既有数学能力。考核页通过 `/mathphysics/api/capabilities` 读取目标，只列出可考核内容；没有静态演示卡片或模式开关。`config/assessment-catalog.json` 是注册表生成的公开目录快照，可运行 `node scripts/build_assessment_catalog.mjs` 更新，页面不再将它作为无服务时的替代入口。

当前基础注册表有 204 个正式目标：

| 类别 | 目标数 | 服务器判定 |
| --- | ---: | --- |
| 当前数与生活/生成练习 | 77 | 固定题量、确定配方、精确数值与题型规则 |
| 固定教学题 | 48 | 服务端固定题快照与客观答案 |
| 几何证明配套考核 | 24 | 固定命题及证明要素题 |
| JSXGraph 配套考核 | 6 | 提交点坐标，按几何约束判定 |
| 七巧板配套考核 | 2 | 提交七块变换，检查覆盖与重叠 |
| PhET 配套考核 | 15 | 面积方格、面积数值、分数拼块与等值配对 |
| 分子配套考核 | 26 | 固定参考图的元素数量与连接关系及数值题 |
| 航天检查题 | 6 | 当前稳定检查题选项；重复引用归同一目标 |

当前航天课程是 0.5.0、63 个阶段。16 处课程检查引用映射到 6 个 canonical 目标；同一检查题被多个任务引用时不会创建多个奖励桶。引用来源校验以当前 `lessons/spaceflight/data.js` 的 SHA-256、阶段 ID 和选项为准，磁盘课程源码未加账号脚本或改动模型。

当前数与生活的 49 个课程单元、现行 help、practice-v2 和题库生成配方继续使用当前教学源码。注册表不会把旧版本配方或旧课程替换进教学页面。题库别名和六个画板入口映射到对应 canonical 目标，不复制奖励目标。

全部1391道无隔离应用题按原分类可练习，仅7道既有问题题保留隔离。取消1123/268固定分区和家族数门槛；来源、故事和题族仅供溯源。1390道映射到40个既有数学目标，1道具体目标待决项单列，仍可练习；不增加目标、奖励桶或隔离。原267条逐题数学关系依据保留，新增映射复用既有分类/数学关系规则，不宣称对1391题进行了新的逐题目标教学审读。所选分类题量不足时由同一目标、同一难度的原生签发器补足原固定题量。同目标与难度继续共用历史最佳增量及原100分上限。人工批准字段如实保持false，真实助手复核记录保留；正式题仍由服务端签发并判原始回答，固定服务端内容指纹保证发布一致性。

## 学习进度与考核成绩

正式题目由服务端独立签发，原课堂不能凭客户端完成按钮、正确标记、拖动轨迹、浏览页数或本机分数领取成长积分。

| 课堂行为 | 可保存记录 | 正式积分 |
| --- | --- | ---: |
| 数与生活/题库练习、导入旧配方 | 配方、当前练习和未核验答题进度 | 0 |
| 几何画板/证明自由探索、七巧板 | 当前控制与完成 checkpoint | 0 |
| PhET 原仿真与物理演示 | 导航及适配表列出的控制 | 0 |
| 航天任务、笔记、实验和检查练习 | 当前稳定阶段、笔记和观察位置 | 0 |
| 新逻辑/空间小游戏 | 现有本机游戏记录及本机积分 | 0 |
| 中文应用题教师复核预览 | 预览与练习记录 | 0 |
| 显式旧浏览器备份导入/恢复 | legacy/unverified 记录 | 0 |

原分子仿真和面积/分数游戏的自由操作不能当成服务器正式题快照。正式配套题只提交服务器公布的结构：分子题比较固定参考图，面积题只允许公开颜色，分数题采用公开拼块、数字卡片或配对 ID。当前固定参考表在 `server/assessment-references.json`，私有参考解答不作为静态文件发布。

## 奖励规则

每个目标、年级分组、难度和兼容版本的历史最佳增量才计分。整数标准化范围 0..10000，每桶最多 100.00 显示点。重复提交、重复同分或换池仍是同家族目标时奖励为 0。具体逐题归因、幂等与修订规则见 [API 合约](api-contract.json) 和 [服务设计](server-learning-plan.md)。
