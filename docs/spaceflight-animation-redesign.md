# 航天阶段动画重做

参考核对日期：2026-10-03。本次已更新航天课堂源码、独立离线页面和 102 张可下载 SVG；下方记录参考依据与实际验证范围。

## 展示原则

- 每个阶段明确呈现「动作前 → 动作中 → 动作后」，提供三个关键画面及对应说明，可暂停、重播和往返拖动。
- 镜头按用户指定原则组织：爬升与入轨时拉远，展示火箭位置和上升轨迹；分离时拉近，展示连接接口和部件离去。缩放与切换镜头保持当前位置连续，避免飞行器突然跳回画面起点。
- 分离时保持部件身份：接口在哪里、哪个部件离开、哪个继续前进，都用稳定的形状、颜色与标签表达。分离件不会在动作开始时立即消失。
- 分级依次表现关机、拉开距离和后续推进。滑行只停止尾焰，不停止飞行器运动；卫星释放表现小的相对位移。
- 二级入轨与一级返回是并行过程。回收画面区分下降方向与减速推力方向，不将一级回收画成载人飞船返航。
- 动作顺序和构型以对应型号资料为依据；镜头距离、动作幅度与播放时长是教学表达，不是比例图、遥测或真实控制参数。

## 保留的型号差异

| 路线 | 必须可见的区别 |
| --- | --- |
| 猎鹰9／载人龙 | 龙飞船直接位于顶部，不使用卫星两瓣式整流罩；龙的尾舱表面供电，不画成早期货运龙的展开太阳翼。一级支腿着陆与龙乘员舱伞降溅落分开。 |
| 猎鹰9／卫星 | 两级分离后，上面级携带卫星继续飞行；两瓣整流罩向外离去，再表现载荷分离。 |
| 长征二号F／神舟 | 两级芯级、四枚捆绑助推器及逃逸塔。正常分离顺序为逃逸塔、助推器、芯一级、整流罩、船箭；正常抛塔不表现成紧急逃逸。 |
| 长征十号乙／卫星 | 两级串联，无长二F的四枚侧助推器。一级挂索机构与海上井字形缓冲拦阻网配合捕获，不使用猎鹰9式着陆腿。回收支线保留独立七段教学流程。 |

## 连续播放与轨迹修订（2026-10-03）

默认连续播放到所选主线或回收流程的末尾；逐段讲解暂停改为可选。阶段交接保留未消费的播放时间，放大窗口与主画面共用进度。猎鹰9回收有八个动作，长十乙保留七段网系回收。

二级入轨段从 9 秒延长至 36 秒：前段持续加速，后段明确关机并继续滑行。上升轨迹复用现有任意教学参数的动力学模型；关机时继承同一地心惯性位置与速度，以二体引力继续 RK4 积分。各阶段共用时间窗口与路径，Hermite 插值保留位置和速度连续性，不再拼接贝塞尔曲线与装饰椭圆。绕地观察段超过一个完整周期。镜头跟随上升，逐渐拉远显示地球全景；分离和展开时保留当前位置小窗。卫星主线调整为分级并点火、整流罩分离、长段二级加速入轨。

一级回收按分离、冷气喷射掉头、越过最高点、再入点火、关机气动下降、着陆点火、展开支腿、接地关机绘制。姿态翻转约半圈，运动方向单独表达；再入点火与着陆点火之间主发动机关闭。八段使用连续姿态与位置，支腿在最终接触时与甲板相接。右上图展示二级与一级并行。该顺航向海上示例未添加返场点火，不把返场程序当作所有海上任务的固定动作。长十乙的具体回收控制时序不套用猎鹰9数据。
