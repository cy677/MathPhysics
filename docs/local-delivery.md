## 使用入口

`npm start -- --open` 继续提供原有静态课堂和浏览器演示进度。需要账号、档案同步与正式积分时，使用 Node.js 24.14.0 启动本地学习服务，访问小写 `/mathphysics/`。初始化、数据库位置与恢复步骤见 [本地学习服务说明](server-learning-operation.md)。

“数与生活”继续保留现有知识点、生成练习、固定题和提示。新增生活应用题按基础池与综合池、类别、子类及 C1/C2/I1/I2 筛选，按类别加载。目录与逐题来源映射见 [应用题整合说明](word-problems-integration.md)。全部1391道无隔离应用题按原分类可练习，仅7道既有问题题保留隔离。取消1123/268固定分区和家族数门槛；来源、故事和题族仅供溯源。1390道映射到40个既有数学目标，1道具体目标待决项单列，仍可练习；不增加目标、奖励桶或隔离。原267条逐题数学关系依据保留，新增映射复用既有分类/数学关系规则，不宣称对1391题进行了新的逐题目标教学审读。所选分类题量不足时由同一目标、同一难度的原生签发器补足原固定题量。同目标与难度继续共用历史最佳增量及原100分上限。人工批准字段如实保持false，真实助手复核记录保留；正式题仍由服务端签发并判原始回答，固定服务端内容指纹保证发布一致性。

演示、预览、提示和练习不增加服务端成长积分。正式考核由服务端发放题目，只接收原始回答；客户端上报的分数不能转成正式积分。同一目标的奖励取历史最佳的提高部分，重复提交有幂等约束，换题或刷新不会另开相同奖励桶。档案之间的存档和积分独立。

## 源码、构建产物和本地资料

交付采用明确的正向文件清单及 SHA-256。源码清单供操作者检查本地提交范围，不提供自动推送命令。数据库、SQLite WAL/SHM、账号资料、备份、凭证、缓存和本地审核输出不在提交或归档范围。现有桌面报告、缓存、数据库不会因本轮清理而删除。

学生离线ZIP仅含运行资源与1391题练习内容，不包含server、tests、题目审计脚本或私有溯源。管理员Node归档含固定发布的判题资料与助手审读记录，必须由操作者保管；默认教学HTTP不会公开server目录。`node scripts/export_word_problems_teacher.mjs --output <静态根外私有路径>` 可单独导出完整教师审读资料，不将其分发给学生。`npm run build:primary` 构建独立的“数与生活”HTML，含1391题本地练习分类题库。`npm run package` 重建离线包；`npm run build:server` 在本地生成带 `BUILD.json` 文件哈希的服务归档。构建本身不部署站点。原库字体、音频和许可证随固定来源保留。

独立 HTML 和静态课堂使用本机零分演示模式。离线可保留已签发考核的原始回答并等待同步，不能离线新发正式考核，也不能把浏览器自算成绩兑为正式积分。
