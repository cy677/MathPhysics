# 学习服务的本地交付

本地与远程统一使用 Node.js 24.14.0 学习服务。Windows 双击 `START_WINDOWS.bat`，或执行 `npm start -- --open`，首次启动引导创建账号，随后打开考核页。默认端口8317，根路径及 `/mathphysics/` 自动进入 `/mathphysics/learning/`。启动、数据库路径和恢复步骤见 [运行说明](server-learning-operation.md)。

静态演示服务器、静态目录回退和演示模式标识已移除。课程、实验及探索页面仍通过学习服务访问。考核页只展示已注册目标，由服务签发试卷并按原始答案判题。已签发试卷的断网续答与待同步队列继续保留。

同一目标、年级、难度与兼容规则允许多次考核，所有答卷分别保存，成绩取最高值。结果页的“再次考核”签发新试卷；重复同分或低分不降低最高成绩，也不重复增加积分。

## 交付文件

`npm run package` 与 `npm run build:server` 均生成 Node 学习服务归档，包含服务、课堂资源和固定的判题资料；不再生成学生静态离线ZIP或在打包中构建单文件课堂。单文件构建工具仅用于现有课堂的回归测试夹具。

数据库、WAL/SHM、账号资料、备份、凭证、缓存及本地审核输出不进入归档。Node HTTP只提供公开学习资源，不公开 `server/` 和私有判题资料。原资源、字体、音频和许可证随固定来源保留。

本次修改在本地工作区完成；构建归档本身不执行远程发布。
