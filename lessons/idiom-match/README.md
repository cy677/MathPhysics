# 成语消消乐 · 随机难度版 v2.0

## MathPhysics 语文模块

从科学小岛首页选择“语文”，进入“成语消消乐”。宿主提供返回、全屏与重玩，当前无需账户，游戏使用本浏览器的存档。原有独立存档可在相同站点的访客模式下迁移，跨设备可通过游戏设置导入原进度 JSON。独立打开 HTML 时仍使用原离线存档。

本目录由原 `成语消消乐_随机难度版` 整体迁入，源码、五档词库和数据来源均保留。在项目根目录运行 `npm run build:idioms`、`npm run test:idioms`，分别重建和检查规则。

## 打开游戏

用桌面浏览器打开 `index.html` 即可使用。页面、样式、规则、原1000条词库与32词练习库均内嵌，不使用 CDN、远程接口、图片或外部字体。查看来源的外部链接需要联网，游戏本身不需要联网。

默认配置：200条词库、轻松难度、每局10个成语。点击牌桌上方的配置名称，可分别设置词库、难度和数量，然后点击“随机开局”。

## 新的对局方式

不再有固定关卡、解锁顺序或星级。普通词库每局重新随机抽取，同一局不重复抽取同一个成语；练习词库每局使用全部词语。不同局允许出现相同词条。

词库范围为200、400、600、800、1000条，逐级包含。每局数量为4—30的任意整数，每个成语拆成前两字和后两字，因此对应8—60张牌。数量快捷项为6、10、15、20、30。大量牌面在较小屏幕上会纵向延伸。

另有“练习词库”：只收录用户提供三张图片中的词语，去重后共32个，每局全部出现，共64张牌；选择后隐藏数量选项。三种难度、提示、洗牌、撤销、拼音和存档规则相同。“换一组”会重新发放这32个词语。图片中的“名川大山”按图保留。原词库已有的词语沿用原编号和收集记录，练习新增词条使用1001起的编号。完整名单见`词库/练习词库.txt`，源数据见`src/practice.json`。

| 难度 | 规则 |
| --- | --- |
| 轻松 | 自由点击或拖动配对，不受位置限制；前后段分色，带“上／下”标记。 |
| 标准 | 正确成语的两张牌须同行或同列且中间无遮挡；可上下左右拖动相邻牌组，形成新的有效配对才保留移动。 |
| 挑战 | 沿用标准规则，取消前后段颜色差异和“上／下”标记；切换到此难度默认隐藏拼音，仍可手动开启。 |

“换一组”重新抽取成语；“重玩”保留当前成语、重新发牌；“洗牌”只改变剩余牌的位置。没有可行动的步骤时自动重排。保留提示、撤销、拼音、简释、成语本、收集记录、音效和设备本地语音功能。不限时。

按可见文字判断配对，不强制必须是原始编号相同的两张牌。抽题时过滤可能导致交叉配对后无法完成残局的组合，保留共有前段或后段的合法配对。由于这一约束，不承诺所有成语组合严格等概率。

## 五档词库与使用频率依据

采用清华大学开放中文词库 THUOCL 成语词表的 DF（Document Frequency），表示**出现该词的文档个数**，不是该词总出现次数，不是百分比。

- 来源项目：https://github.com/thunlp/THUOCL
- 原始词表：https://github.com/thunlp/THUOCL/blob/master/data/THUOCL_chengyu.txt
- 语料：新浪新闻，2008年1月—2016年11月，共8,421,097篇文档。
- 成语源词表：8,519条；项目标注的更新时间：2016-12-24。
- 本次核对的源文件 Git blob SHA：`44d91b3349753dc7f43b53e8cf64cda790c9ea22`。
- 本次核对日期：2026-10-15。

**本版保留原游戏的1000条成语，不另行抽取“全汉语成语前1000名”。** 原词库中937条匹配到来源词条，63条未匹配到。937条按DF降序，同值按原id升序；未匹配的63条附于末尾，DF记为`null`，不赋零、不套用异形词数值、不据此认定低频。

| 词库 | 有同来源DF | 未匹配到来源词条 |
| --- | ---: | ---: |
| 200条 | 200 | 0 |
| 400条 | 400 | 0 |
| 600条 | 600 | 0 |
| 800条 | 800 | 0 |
| 1000条 | 937 | 63 |

较小词库是较大词库的前缀子集。所有词库可在“成语本 → 分档词库”中浏览和搜索；每条显示库内序号和DF或未匹配说明。`词库/`目录另提供各档JSON和纯文本文件。

新闻语料具有文体和年代偏向，不是2026年的实时统计；高使用频率不等于儿童容易理解。五档不是教育部规定的年级词表，也不是学校必背清单。词库范围与玩法难度分别设置。

拼音和入门简释沿用原游戏，不由THUOCL提供，不代表已获该项目审定。简释只呈现主要常用含义，不替代完整辞书。

## 数据字段

`id`为旧版稳定编号，用于收集记录迁移；`rank`为本游戏的排列位置，不是全国词频名次。`minimumPool`为首次进入的词库大小。`frequency.df`为文档频次或`null`；`frequency.status`为`exact_match`或`not_matched`；`frequency.source_id`指向来源元数据。

`research/thuocl_matched.tsv`保存937个匹配词条及其来源数值，**不是8519条完整原始词表**；`research/未匹配词条.txt`保存63条未匹配词条。完整的来源口径、排序规则和限制见`src/source.json`。

## 进度与旧版迁移

新版存储键为`idiom-match-random-v2`。可访问旧版同一浏览器存储时，会迁移原有已收集成语；也可导入旧版导出的进度JSON。旧版关卡、星级和未完成关卡的牌面不迁移，新版使用随机牌局。

点击右上角设置按钮可导出、导入进度。移动HTML文件、更换浏览器或设备、清除浏览器数据后，不保证自动找到旧存档，请先导出备份。禁用存储时仍可玩，但会显示无法保存提示。不会通过网络上传进度。

## 重建与测试

运行游戏不需要Python或Node。修改源码后重建：

```sh
python src/build.py
```

重建脚本先重新按已核对的DF表生成五档词库，再输出单文件`index.html`。仅需Python标准库。

规则测试：

```sh
node src/test_core.cjs
```

在 MathPhysics 项目根目录运行 `npm run test:idioms:browser`，可检查练习词库三档完整通关、进度导入导出、手机布局、宿主集成与单文件离线使用。

浏览器测试需要Python Playwright及Chromium。当前脚本默认使用`/usr/bin/chromium`；其他系统请修改该路径。

```sh
python src/test_browser.py
```

可另外下载完整原始词频表，执行独立的逐条比对（本次未在容器中运行此可选完整文件比对）：

```sh
python src/verify_thuocl.py /path/to/THUOCL_chengyu.txt
```

本次实测覆盖与限制见`测试说明.md`，机器可读结果在`src/core_test_results.json`和`src/browser_test_results.json`。
